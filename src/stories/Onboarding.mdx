## 📖 Quick Start Guides

### Creating Your First Dialogue

1. Go to <a href="?path=/story/🎙️-recording-audio-recording-studio--coffee-shop-dialogue" style={{ color: '#667eea', fontWeight: 'bold', textDecoration: 'none' }}>**Recording Audio → Coffee Shop Dialogue**</a>
2. Click **Add Speaker** to create a character
3. Type what they say in the dialogue field
4. Click the **microphone icon** to generate audio
5. Press **play** to hear it!

### Building a Vocabulary List

1. Navigate to <a href="?path=/docs/📁-managing-content-vocabulary-review--docs" style={{ color: '#667eea', fontWeight: 'bold', textDecoration: 'none' }}>**Managing Content → Vocabulary Review**</a>
2. Click **Add Word** 
3. Enter the word, pronunciation, and definition
4. Optionally add audio files or images
5. Use tags to organize your vocabulary

### Designing a Quiz

1. Go to <a href="?path=/docs/📁-managing-content-questions-review--docs" style={{ color: '#667eea', fontWeight: 'bold', textDecoration: 'none' }}>**Managing Content → Questions Review**</a>
2. Click **Add Question**
3. Type your question and answer
4. Choose question type (multiple choice, short answer, etc.)
5. Add hints or explanations for students

### Using the AI Chat Assistant

1. Find <a href="?path=/docs/💬-ai-assistant-chat-sidebar--docs" style={{ color: '#667eea', fontWeight: 'bold', textDecoration: 'none' }}>**AI Assistant → Chat Sidebar**</a>
2. Type a question like "Help me create a lesson about seasons in Japanese"
3. The AI will suggest content, translations, and ideas
4. You can ask follow-up questions anytime

## 💡 Tips for Success

### Visual Formatting

When writing dialogue or scripts:
- **Speaker names**: Use UPPERCASE (ALICE, BOB)
- **Stage directions**: Put in (parentheses) after the name
- **Emotions**: Add [in brackets] for tone
- **Example**: `ALICE (smiling) [cheerfully]`

### Keyboard Shortcuts

Speed up your work with these shortcuts:
- `Ctrl+Z` / `Cmd+Z` - Undo
- `Ctrl+Y` / `Cmd+Y` - Redo
- `Ctrl+S` / `Cmd+S` - Save (if enabled)
- `Ctrl+Enter` - Generate audio (in recording studio)

### Best Practices

- **Upload Textbook Material** - Use real content for authenticity
- **Start simple** - Add basic content first, then enhance it
- **Use examples** - Copy patterns from the example stories
- **Ask the AI** - When stuck, use the chat assistant for help
- **Preview as Student** - Use read-only mode to see the student experience

## ❓ Common Questions

**Q: Can I save my work?**  
A: In Storybook, you can export JSON. In the real app, everything saves to AWS automatically.

**Q: What if I make a mistake?**  
A: Press `Ctrl/Cmd + Z` to undo, or refresh to start over in Storybook.

**Q: How do I add my own images?**  
A: Go to [File Manager](?path=/docs/📁-managing-content-file-manager--docs) and upload your files.

**Q: Can I export my lessons?**  
A: Yes! Most stories have a "Download" or "Export JSON" option.

**Q: Does this work offline?**  
A: Most features work offline. Only the AI assistant requires internet.

## Workflows: Manual vs AI-Assisted

### Creating a Section (Class)

**Manual Approach:**
1. Go to Sections page
2. Click "Create Section" button
3. Enter section name (e.g., "Japanese 101 - Spring 2026")
4. Set grade level and description
5. Get unique join code for students

**AI-Assisted Approach:**
1. Open AI Chat
2. Ask: "Create a section for beginner Japanese students"
3. AI suggests section structure with name and description
4. Review and confirm to create

### Creating a Unit

**Manual Approach:**
1. Click "New Unit" from Units page
2. Enter title and description
3. Use editor to add content blocks
4. Insert media, vocabulary, questions
5. Save and publish

**AI-Assisted Approach:**
1. Open AI Chat in a new/existing unit
2. Ask: "Create a unit teaching Japanese greetings with quiz questions"
3. AI generates outline with sections and content
4. Review suggested content forms (quiz, vocab, explanations)
5. Click "Insert" on forms you want to add
6. AI adds blocks directly to editor
7. Iterate: "Add more examples" or "Make it easier for beginners"

### Creating an Assignment

**Manual Approach:**
1. Go to Sections page, select a section
2. Click "Create Assignment"
3. Select unit from dropdown
4. Set due date and time
5. Choose assignment settings (allow late, show answers after)
6. Assign to section

**AI-Assisted Approach:**
1. Open AI Chat
2. Ask: "Create an assignment for Japanese 101 using the Greetings unit, due next Friday"
3. AI suggests assignment with recommended settings
4. Review and confirm to create
5. AI handles unit selection, date calculation, and optimal settings

## Architecture Patterns

### React Contexts (Avoid DataStore duplication)
- `UnitContext` - Unit data, files, dictionary, grading
- `SectionContext` - Classes and assignments
- `FilesContext` - File management
- `DictionaryContext` - Words and questions

### DataStore Best Practices
```javascript
// ✅ Good - One subscription, client-side filter
DataStore.observeQuery(Grade).subscribe(({ items }) => {
  const myGrades = items.filter(g => g.userID === userId);
});

// ❌ Bad - Multiple subscriptions
DataStore.observeQuery(Grade, g => g.userID.eq(userId));
DataStore.observeQuery(Grade, g => g.complete.eq(true));
```

### Editor Data Flow
1. Content stored as JSON in `Unit.data` field
2. Lexical parses JSON into editor state
3. Custom nodes render graded blocks
4. Save via `saveEditorContent()` from UnitContext

### Grading System
- `Grade.data` stores student responses as JSON
- Auto-calculated accuracy from rubric
- Rubric built from graded block types: `quiz`, `answer`, `meaning-association`, `custom-answer`
