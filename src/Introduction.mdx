# Homework Supply - Component Documentation

Welcome to the Homework Supply component documentation. This is a comprehensive Japanese language learning platform built with Next.js, AWS Amplify Gen 1, and OpenAI.

## 🏗️ Architecture

**Stack**: Next.js 16 + AWS Amplify Gen 1 (GraphQL/DataStore) + Material UI + Lexical Editor + OpenAI

**Database**: DynamoDB via Amplify DataStore with real-time sync

**Auth**: AWS Cognito with user groups (Admins, Instructors, Learners)

**Storage**: S3 for files (audio/video/PDFs), organized by protection level

**AI Features**: OpenAI API (GPT-4, Whisper, TTS) via Lambda + Vercel AI SDK for streaming chat

## 🎨 Mocking Strategy

All AWS services are mocked in Storybook for safe, isolated component development:

- **AWS Amplify** modules (api, auth, storage, datastore, utils) are mocked via webpack aliases
- **AI generation** (text-to-image, text-to-speech) with realistic delays
- **File storage** and retrieval with placeholder data URLs
- **Authentication** with mock credentials
- **DataStore** operations with in-memory storage
