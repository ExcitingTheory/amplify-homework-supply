# Instructor Onboarding - Quiz Mode Navigation Instructions

This document provides specific Storybook navigation links for each instructor onboarding task in Quiz Mode. Instead of directing users to generic "Application Pages", these instructions link directly to the relevant component stories where they can practice.

---

## Task 1: Set Up Your First Class

**Task ID**: `instructor-setup-class`

### Quiz Mode Instructions

Navigate to practice creating sections:

**📄 [Pages → Sections](?path=/story/📄-pages-application-pages--sections)**

Or try the interactive sections component:

**🧩 [Components → Section Assigner](?path=/story/components-sectionassigner--default)**

### Steps to Complete:
1. Navigate to the **Sections** story using the link above
2. Click the "Create Section" button
3. Enter a class name (e.g., "Japanese 101")
4. Configure grade level and settings
5. Save your section
6. Note the auto-generated join code for students

### What You'll Practice:
- Creating new class sections
- Configuring section settings
- Understanding join codes
- Managing student groups

## Task 2: Create Your First Unit

**Task ID**: `instructor-create-unit`

### Quiz Mode Instructions

Navigate to the Units page to create learning content:

**📄 [Pages → Units](?path=/story/📄-pages-application-pages--units)**

Or jump straight to the editor interface:

**📚 [Creating Lessons → Editor](?path=/story/📚-creating-lessons-editor--default)**

View the full unit editor example:

**📚 [Creating Lessons → Editor → Unit Detail](?path=/story/📄-pages-application-pages--unit-detail)**

### Steps to Complete:
1. Navigate to **Units** using the link above
2. Click "Create New Unit"
3. Enter a title (e.g., "Japanese Greetings")
4. Use the Lexical Editor to add:
   - Headings and formatted text
   - Images or media
   - Educational content blocks
5. Save your unit

### What You'll Practice:
- Creating new learning units
- Using the Lexical editor interface
- Basic text formatting
- Adding media content
- Unit management workflow

## Task 3: Add a Quiz Block

**Task ID**: `instructor-add-quiz`

### Quiz Mode Instructions

Practice adding quiz blocks in the editor:

**📚 [Creating Lessons → Editor → Quiz Plugin](?path=/story/📚-creating-lessons-editor-plugins-quizplugin--default)**

See the full editor with quiz support:

**📚 [Creating Lessons → Editor](?path=/story/📚-creating-lessons-editor--default)**

### Steps to Complete:
1. Navigate to the **Quiz Plugin** story
2. In the editor, type `/` to open the command menu
3. Select "Quiz" from the block options
4. Enter your question text
5. Add 2-4 answer choices
6. Mark the correct answer with the checkbox
7. Save the content

### What You'll Practice:
- Using the `/` command menu
- Creating multiple choice questions
- Configuring answer options
- Understanding graded content blocks
- Quiz assessment setup

## Task 4: Add Vocabulary Words

**Task ID**: `instructor-create-vocabulary`

### Quiz Mode Instructions

Practice adding vocabulary with the Word Block plugin:

**📚 [Creating Lessons → Editor → Word Block Plugin](?path=/story/📚-creating-lessons-editor-plugins-wordblockplugin--default)**

Or use the standalone vocabulary review component:

**🧩 [Components → Vocabulary Review 2](?path=/story/components-vocabularyreview2--default)**

### Steps to Complete:
1. Navigate to the **Word Block Plugin** story
2. Click "Add Word" or use the `/` menu
3. Enter:
   - Japanese word (kanji/kana)
   - Romanization (romaji)
   - English definition
4. Optionally add audio pronunciation
5. Link the word to your unit
6. Save to the dictionary

### What You'll Practice:
- Adding vocabulary words
- Using the dictionary system
- Audio file management
- Linking words to units
- Building class vocabulary

## Task 5: Assign Work to Students

**Task ID**: `instructor-create-assignment`

### Quiz Mode Instructions

Navigate to section detail to create assignments:

**📄 [Pages → Section Detail](?path=/story/📄-pages-application-pages--section-detail)**

Or use the Section Assigner component:

**🧩 [Components → Section Assigner](?path=/story/components-sectionassigner--default)**

### Steps to Complete:
1. Navigate to **Section Detail** using the link above
2. Find your section and open it
3. Click "Create Assignment"
4. Select a unit to assign
5. Set:
   - Due date and time
   - Assignment settings (attempts, time limits)
6. Assign to your section
7. Confirm students can see it

### What You'll Practice:
- Creating assignments
- Setting due dates
- Configuring assignment options
- Managing section assignments
- Understanding student visibility

## Task 6: View Student Grades

**Task ID**: `instructor-view-grades`

### Quiz Mode Instructions

View grades in the section detail gradebook:

**📄 [Pages → Section Detail](?path=/story/📄-pages-application-pages--section-detail)**

See student perspective in the workbook:

**📄 [Pages → Workbook](?path=/story/📄-pages-application-pages--workbook)**

1. Navigate to **Section Detail**

- Navigating the gradebook
- Viewing student submissions
- Understanding accuracy scoring
- Reviewing student work
- Providing feedback

## Task 7: Use AI to Generate Content

**Task ID**: `instructor-use-ai-assistant`

### Quiz Mode Instructions

Practice using AI content generation:

**🤖 [Components → Chat Sidebar](?path=/story/components-chatsidebar--default)**

See AI in the editor context:

**📚 [Creating Lessons → Editor → AI Content Completion](?path=/story/📚-creating-lessons-editor-plugins-aicontentcompletionplugin--default)**

6. Customize as needed
7. Save your unit

### What You'll Practice:
- Using the AI chat interface
- Prompting AI for specific content
- Reviewing and editing AI suggestions
- Inserting AI-generated content
- Customizing AI output
- Efficient content creation workflow

## Task 8: Master Editor Shortcuts

**Task ID**: `instructor-learn-shortcuts`

### Quiz Mode Instructions

Learn keyboard shortcuts with the interactive trainer:

**⌨️ [Help → Keyboard Shortcuts](?path=/story/help-keyboard-shortcuts--keyboard-shortcut-trainer)**

See shortcuts in action:

**⌨️ [Help → Keyboard Shortcuts Demo](?path=/story/help-keyboard-shortcuts--automated-demo)**

Practice in the editor:

**📚 [Creating Lessons → Editor](?path=/story/📚-creating-lessons-editor--default)**

### Steps to Complete:
1. Navigate to **Keyboard Shortcuts** trainer
2. Review the most useful shortcuts:
   - **Bold**: ⌘B (Mac) / Ctrl+B (Windows)
   - **Italic**: ⌘I / Ctrl+I
   - **Underline**: ⌘U / Ctrl+U
   - **Heading 1**: ⌘⇧1 / Ctrl+Shift+1
   - **Bullet List**: ⌘⇧7 / Ctrl+Shift+7
   - **Numbered List**: ⌘⇧8 / Ctrl+Shift+8
   - **Align Left**: ⌘⇧L / Ctrl+Shift+L
   - **Align Center**: ⌘⇧E / Ctrl+Shift+E
   - **Undo**: ⌘Z / Ctrl+Z
   - **Redo**: ⌘⇧Z / Ctrl+Shift+Z
3. Watch the automated demonstration
4. Practice shortcuts in the editor
5. Keep the help page open for reference

### What You'll Practice:
- Text formatting shortcuts
- Block type shortcuts (headings, lists)
- Alignment shortcuts
- Navigation shortcuts
- Undo/redo workflow
- Efficiency in content creation

## Navigation Tips

### Using Story Links

All links above use the format:
```
?path=/story/[category]-[component]--[story-name]
```

### Quick Navigation

In Storybook:
1. Use the **sidebar** to browse categories
2. Use **search** (⌘K / Ctrl+K) to find stories quickly
3. Use **breadcrumbs** at the top to navigate back
4. **Bookmark** frequently used stories

### URL Pattern Reference

Common story prefixes:
- `📄-pages-application-pages--*` - Full page examples
- `📚-creating-lessons-editor--*` - Editor and plugins
- `🧩-components-*` - Individual components
- `⌨️-help-keyboard-shortcuts--*` - Help and training

### Opening Links

From Quiz Mode instructions:
1. **Click the link** in the instructions card
2. **Link opens in same window** - story loads directly
3. **Use browser back** to return to quiz instructions
4. **Onboarding panel stays open** to track progress

### Progress Tracking

Your progress is tracked automatically:
- ✅ **Automatic detection** when you complete actions
- 📊 **Progress shown in sidebar** Onboarding panel
- 💾 **Saved to localStorage** - persists across sessions
- 🎯 **Quiz mode shows** task instructions only
- 📈 **Tutorial mode shows** embedded demos

## Updating Quiz Mode Component

To update the QuizMode component to use these instructions:

1. **Edit** `.storybook/components/QuizMode.tsx`
2. **Replace** the generic "Application Pages" navigation
3. **Add** task-specific story links from this document
4. **Update** the navigation button to use the primary story link
5. **Test** each link to ensure it navigates correctly

Example implementation:

```tsx
const TASK_NAVIGATION = {
  'instructor-setup-class': {
    primary: '?path=/story/📄-pages-application-pages--sections',
    label: 'Open Sections Page',
    alternatives: [
      { url: '?path=/story/components-sectionassigner--default', label: 'Section Assigner Component' }
    ]
  },
  'instructor-create-unit': {
    primary: '?path=/story/📄-pages-application-pages--units',
    label: 'Open Units Page',
    alternatives: [
      { url: '?path=/story/📚-creating-lessons-editor--default', label: 'Editor' },
      { url: '?path=/story/📄-pages-application-pages--unit-detail', label: 'Unit Detail' }
    ]
  },
  // ... etc
};
```
