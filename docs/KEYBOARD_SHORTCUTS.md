# Keyboard Shortcuts - Homework Supply

Comprehensive list of keyboard shortcuts available in the Homework Supply Editor and Application.

## 📝 Editor - Text Formatting

| Command | Windows/Linux | Mac | Description |
|---------|---------------|-----|-------------|
| **Bold** | `Ctrl + B` | `⌘ B` | Make selected text bold |
| **Italic** | `Ctrl + I` | `⌘ I` | Make selected text italic |
| **Underline** | `Ctrl + U` | `⌘ U` | Underline selected text |

## 🎯 Context-Specific Shortcuts

### Code Blocks
- **Syntax Highlighting**: Automatically applied based on language
- **Indentation**: `Tab` for indent, `Shift + Tab` for outdent within code

### Lists
- **Exit List**: Press `Enter` twice on empty list item
- **Indent Item**: `Tab` to create nested list
- **Outdent Item**: `Shift + Tab` to decrease nesting

### Links
- **Auto-Link**: Type or paste URL - automatically converts to clickable link
- **Email Links**: Type email address - automatically converts to mailto: link

## 📋 Markdown Shortcuts

| Type | Result |
|------|--------|
| `# ` | Heading 1 |
| `## ` | Heading 2 |
| `### ` | Heading 3 |
| `- ` or `* ` | Bullet list |
| `1. ` | Numbered list |
| `> ` | Block quote |
| ` ``` ` | Code block |
| `---` | Horizontal rule |

## ⚠️ Browser-Specific Notes

Some shortcuts may be overridden by browser defaults:
- **`Ctrl/⌘ + P`**: Print (browser default) - not used in editor
- **`Ctrl/⌘ + F`**: Find (browser default) - not used in editor
- **`Ctrl/⌘ + S`**: Save (captured for auto-save in editor)

## 💡 Pro Tips

1. **Multiple Shortcuts**: Some actions (like undo/redo) have multiple shortcuts for user preference
2. **Context Matters**: Shortcuts behave differently based on what's selected (text vs block vs table)
3. **Modifier Keys**: 
   - `Ctrl` (Windows/Linux) = `⌘` (Mac)
   - `Alt` (Windows/Linux) = `⌥` (Mac)
   - `Shift` = `⇧` (universal)
4. **AI Features**: AI suggestions only appear after typing complete sentences (50+ characters)
5. **Block Selection**: Click on blocks to select them, then use keyboard to delete or navigate

## 🔧 Customization

Currently, keyboard shortcuts are not user-customizable. This is a planned feature for future releases.
