**Generated Content**:
```markdown
## Japanese Particles (助詞)

Particles are small words that follow nouns, verbs, or adjectives to indicate their grammatical function in a sentence. They are essential for understanding Japanese sentence structure.

### Key Points

- **は (wa)**: Topic marker - indicates what the sentence is about
  - Example: 私**は**学生です (I am a student)
  
- **が (ga)**: Subject marker - marks the grammatical subject
  - Example: 犬**が**います (There is a dog)
  
- **を (wo/o)**: Object marker - marks the direct object
  - Example: りんご**を**食べます (I eat an apple)
  
- **に (ni)**: Direction/time/location marker
  - Example: 学校**に**行きます (I go to school)
  
- **で (de)**: Location of action or means
  - Example: 図書館**で**勉強します (I study at the library)

### Common Mistakes

Students often confuse は (wa) and が (ga). Remember: は indicates the topic (what you're talking about), while が marks the subject (what's doing the action).
```

```markdown
## Summary: Japanese Verb Conjugation

Japanese verbs conjugate based on tense, politeness level, and whether the statement is positive or negative. Understanding conjugation patterns is fundamental to expressing yourself in Japanese.

### Main Takeaways

1. **Three Verb Groups**
   - う-verbs (Godan): Verbs ending in う, く, ぐ, す, つ, ぬ, ぶ, む, る
   - る-verbs (Ichidan): Verbs ending in -eru or -iru
   - Irregular: する (suru) and 来る (kuru) only

2. **Essential Forms**
   - **Dictionary form**: Base form (食べる, 行く)
   - **Polite form**: Add ます (食べます, 行きます)
   - **Past tense**: た/だ (食べた, 行った)
   - **Negative**: ない (食べない, 行かない)
   - **て-form**: Connecting form (食べて, 行って)

3. **Conjugation Rules**
   - る-verbs: Simply remove る and add suffix
   - う-verbs: Change the final sound before adding suffix
   - Practice makes perfect - irregular patterns become natural with repetition

4. **Common Mistakes to Avoid**
   - Don't confuse る-verbs with う-verbs ending in る
   - Remember: 帰る (kaeru) is an う-verb, not a る-verb
   - Pay attention to the sounds in the syllable before る

### Next Steps

Practice conjugating 10 common verbs in all forms. Focus on recognizing which verb group each belongs to before attempting conjugation.
```

**User Request**: "Create content explaining the difference between は and が with examples"

**Generated Content**:
```markdown
## Understanding は (wa) vs が (ga)

One of the most challenging aspects of Japanese grammar is knowing when to use は (wa) versus が (ga). Both are particles, but they serve different grammatical functions.

### は (wa) - Topic Marker

**Purpose**: Indicates what the sentence is about (the topic)

**When to use:**
- Introducing a topic for discussion
- General statements or facts
- Contrasting with other topics

**Examples:**
```
私は学生です。
Watashi wa gakusei desu.
(I [topic] am a student)

東京は大きいです。
Toukyou wa ookii desu.
(Tokyo [topic] is big)

コーヒーは好きですが、紅茶は好きじゃないです。
Koohii wa suki desu ga, koucha wa suki janai desu.
(I like coffee [topic], but I don't like black tea [topic])
```

### が (ga) - Subject Marker

**Purpose**: Marks the grammatical subject of the sentence

**When to use:**
- Answering "who" or "what" questions
- Describing something new or unknown
- With adjectives of desire (欲しい, したい)
- With certain verbs (ある, いる, できる, わかる)

**Examples:**
```
誰が来ましたか？ 田中さんが来ました。
Dare ga kimashita ka? Tanaka-san ga kimashita.
(Who came? Tanaka-san [subject] came)

犬がいます。
Inu ga imasu.
(There is a dog [subject])

日本語が分かります。
Nihongo ga wakarimasu.
(I understand Japanese [subject])
```

### Key Differences

| は (wa) | が (ga) |
|---------|---------|
| Marks the topic | Marks the subject |
| Known/established information | New/unknown information |
| Broad, general statements | Specific, focused statements |
| Can have multiple in a sentence | Usually one per clause |

### Practice Tips

1. **Question Method**: If asking "What about X?", use は. If asking "Which one?", use が.
2. **New vs Known**: New information uses が, known information uses は.
3. **Listen to natives**: Pay attention to particle usage in real conversations.

### Common Patterns

**Always が:**
- 〜が好き (to like)
- 〜が欲しい (to want)
- 〜ができる (can do)
- 〜がわかる (to understand)
- 〜がある/いる (to exist)

**Usually は:**
- General descriptions
- Habitual actions
- Established facts
- Contrasts
```

## How to Use Generated Content

1. **Ask the chatbot** for content using natural language
2. **Review the generated markdown** in the chat response
3. **Copy the markdown** from the chat
4. **Paste into the editor** - Lexical will automatically convert markdown to rich nodes
5. **Edit as needed** using the editor's formatting tools

The editor supports markdown shortcuts via `@lexical/markdown`:
- `#` for headings
- `-` or `*` for lists
- `**bold**` for bold text
- `*italic*` for italic text
- Tables, code blocks, and more
